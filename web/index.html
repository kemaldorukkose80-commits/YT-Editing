🎬 YT-Editing

Üretim yöntemi

1) Ses dosyan

mp3 / m4a / wav… Uzun videolar için m4a 64–96 kbps mono önerilir (dosya küçük kalır, 1,5 saat ≈ 45 MB).

2) Video metnin (senaryo)

Seslendirdiğin metnin aynısı olmalı — sistem cümleleri sese göre hizalar.

3) İsteğe bağlı: Elle yazı efektleri (opsiyonel)

Boş bırakırsan sistem ilk 3-5 önemli sayı/para/isim'i otomatik seçer (giriş/hook kısmına öncelik verir). Elle belirtmek için her satıra: dakika:saniye | YAZI

4) İsteğe bağlı: Gelişmiş ayarlar

Henüz iş yok.

API Anahtarları

Anahtarlar yalnızca bu sunucuda settings.json içinde saklanır, Git'e girmez. Ücretsiz Brave planı saniyede 1 istek kabul eder — sistem bunu otomatik yavaşlatır ve sorguları önbellekler.

GitHub

İşler bu dala yüklenir ve Render Video workflow'u tetiklenir. Anahtarları GitHub → Settings → Secrets → Actions kısmına BRAVE_API_KEY ve PEXELS_API_KEY olarak da eklemelisin.

Varsayılan ayarlar

iPad ile kullanım (adım adım)

  1. API anahtarlarını ekle — ⚙️ Ayarlar sekmesine Brave ve Pexels anahtarlarını gir, kaydet. Aynı anahtarları GitHub deposunda Settings → Secrets and variables → Actions → New repository secret yolundan BRAVE_API_KEY ve PEXELS_API_KEY olarak da ekle.
  2. Yeni Video sekmesinde yöntem seç — normal işler için ☁️ GitHub Actions ile üret.
  3. Ses dosyanı seç, metnini yapıştır, başlık yaz ve Üretimi Başlat'a bas. Hepsi bu — Actions videoyu üretir.
  4. İşler sekmesinden ilerlemeyi izle. Bitince GitHub Releases sayfasından MP4'ü iPad'ine indir.
  5. Sunucu/uygulama kapalıyken bile: GitHub sitesinden Add file → Upload files ile jobs/videonun-adi/ klasörüne ses + script.txt yükle, Actions → Render Video → Run workflow de, iş adını yaz, başlat.

Nasıl çalışır?

  • Ses–metin hizalaması oransal dağıtım + sessizlik kenetleme ile yapılır (her cümle ~5-6 sn'lik sahnelere düşer).
  • Her sahne için anahtar kelimelerle fotoğraf (Brave) veya stok video (Pexels) çekilir; fotoğraflara Ken Burns, her değişimde kısa fade geçişi uygulanır.
  • Metinde geçen önemli para/sayı/isim bilgileri sade bir yazı efektiyle ekrana gelir (video başına 3-5, giriş bölümüne öncelik).
  • Sorgular diskte önbelleklenir — aynı konu tekrar sorulduğunda API kotası harcanmaz.
